# 当代年轻人精神状态检测 · 项目完整总结

## 一、项目定位

“当代年轻人精神状态检测”是一款可离线运行的单文件网页趣味测试。玩家回答 16 道日常情境题后，系统根据选择累积分数，从 8 种倾向中生成一份带有类型名称、行为特征、指数和温和建议的娱乐化报告。

项目同时提供“办公保护模式”：娱乐页面可以一键切换为“员工工作状态与协作体验调研”，题目和结果改用正式表达，底层评分逻辑保持一致。该功能构成项目最鲜明的传播记忆点。

## 二、核心体验流程

```text
进入首页
→ 开始检测
→ 回答 16 道情境选择题
→ 可返回上一题修改
→ 可随时切换娱乐/办公模式
→ 等待模拟分析
→ 获得检测报告
→ 复制分享文案或打开二维码入口
```

## 三、主要功能

- 16 道生活情境选择题。
- 8 类结果：社交型、共情型、敏感型、低电量型、过度思考型、直球型、计划型和平衡型。
- 答题进度和题目序号显示。
- 返回上一题并撤销旧评分。
- 娱乐模式与办公保护模式双向切换。
- `Esc` 进入办公模式，`Alt+Q` 双向切换。
- 检测加载动画和结果逐项出现动画。
- 结果页包含类型名、内部代号、危险指数、四项倾向比例、近期行为和建议。
- 系统分享与复制结果文案。
- 二维码入口。
- Emoji 字体检测和文字备用符号。
- 单文件运行，不依赖构建工具。

## 四、技术结构

成品由两个文件组成：

```text
index.html   完整页面、样式、题库、评分和交互逻辑
README.txt   版本说明、使用方式和自检结果
```

CSS 与 JavaScript 全部内嵌在 `index.html` 中。用户解压后双击即可运行，也可以把 `index.html` 放到静态网站根目录部署。

## 五、内容与表达策略

题目不直接询问抽象人格，而是使用“临时邀约”“老板找你聊一下”“凌晨想起尴尬瞬间”“计划临时改变”等具体场景。玩家只需选择最接近真实反应的答案，降低理解成本，也更容易产生代入感。

结果文案采用“扎心但不诊断”的原则：可以放大互联网生活梗，但不会把娱乐测试包装成医学或心理诊断。页面末尾明确注明“娱乐测试，不是医学诊断”。

## 六、教程交付逻辑

配套教程按照以下顺序组织：

1. 用一句问题引出互动测试。
2. 展示首页和核心体验。
3. 给出可复用的开工提示词。
4. 解释为什么先审蓝图。
5. 展示娱乐答题页。
6. 讲解办公保护模式。
7. 给出试玩与截图反馈方法。
8. 展示加载和结果报告。
9. 说明分享、二维码和离线打包。
10. 总结可复用的 Codex 制作流程。

## 九、已知边界

- 答题答案只在当前页面打开期间保留；刷新网页后会重新开始。
- 页面主体可以断网运行，但二维码由在线服务生成，严格断网时不可用。
- 附件中的二维码为任务阶段的示意内容；项目正式上线后应换成实际测试地址重新截图。
- 当前视频是由关键试玩画面组成的静音预览，不包含鼠标轨迹、旁白或背景音乐。
