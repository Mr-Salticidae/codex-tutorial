听课词汇小抄

不用背 · 听课时碰到哪个不认识，回来查一眼就行
程序 / 代码
给电脑的说明书 / 写说明书用的语言
运行
让电脑照着说明书执行一遍
bug
说明书里的漏洞，会导致结果不对
调试（debug）
找漏洞、补漏洞
报错
执行不下去时甩给你的英文说明，复制丢给 AI 即可
终端 / 命令行
用打字跟电脑对话的黑框框，Codex 会替你操作
项目 / 项目文件夹
一个作品的全部文件，集中放在一个文件夹里
前端
产品的「脸面」，你看得见、点得到的界面
后端
产品的「后厨」，在幕后干活的部分
HTML
网页文件的格式，双击就能用浏览器打开
部署 / 上线
把作品搬到网上，让所有人都能访问
Git / GitHub
代码的「游戏存档系统」和「云端网盘」，随时读档回滚
Skill
教 AI 干某类活的「岗前培训手册」
MCP / CLI
AI 连接其他软件和服务的「转接头」
你不需要成为程序员 · 只需要说得清需求、看得懂效果
