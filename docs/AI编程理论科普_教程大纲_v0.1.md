# AI编程理论科普 · 教程大纲 v0.1

> 起草日期：2026-07-20。
> 对应母教程位置：「Codex基础功能展示」章节首节「AI编程理论科普（跳）」，原占位提示语：「什么是AI编程？AI编程的逻辑是怎么样的?」。
> 与前三板块不同：本板块为**纯理论科普**，无源项目可反推，事实基础为概念讲解与公开常识（vibe coding 词源等），不涉及项目 git 历史。

## 一、板块定位与写作原则

- 位置在 PART2 开头、软件界面介绍之前：学员刚看完下载安装和版本科普，还没开始动手。本节的任务是**把心智模型建好**，让后面所有实战「顺理成章」。
- 全程无操作、无门槛：不出现任何需要学员跟做的步骤。
- 遵循学员版减负三原则的理论版变体：**只建直觉、不讲原理**（不讲神经网络/token/上下文窗口这类概念）；所有抽象概念配生活类比；术语后置成「词汇小抄」供回查。
- 与前文呼应不重复：课程引言已讲过「Codex 是智能体/智能管家」，本节从**编程视角**加深这一区别，明确引用「前面章节」而不重讲。
- 向后勾连：结尾点明「后面所有实战都是这个循环的重复」，为各实战板块「你说一段话，Codex 给一个结果」的固定节奏埋线。

## 二、内容结构（7 节）

```text
0. 开场：三个问题                 —— 本节无操作，但想通三个问题，后面全顺
1. 编程到底是在干嘛               —— 程序=给电脑的说明书；代码=说明书的语言（机器人做饭类比）
2. 以前编程为什么难               —— 三道门槛：学语法（外语）/搭环境（工作台）/修报错（最较真的读者）
3. AI 来了之后                    —— 大模型=会所有编程语言的翻译+老师傅；门槛从「会写」降到「会说」
4. 从「嘴替」到「帮手」           —— Chat 只负责说，Agent 负责做；你从操作工变成提需求做验收的甲方
5. vibe coding：玩法的名字        —— 词源（2025 年初 Karpathy）；核心=「说→做→看→改」四步循环（配循环图）
6. 小白上路前的三个心态           —— ①代码看不懂没关系，效果看得懂就行
                                     ②出错不可怕：报错丢回去让 AI 自己修，Git 存档可回滚
                                     ③说得越具体结果越好：给谁用/有什么功能/长什么样（好坏描述对比）
7. 听课词汇小抄                   —— 14 个高频词一句话人话解释，不用背、听到回查
```
