> 遵循学员版减负三原则：工具只讲「是谁、管什么」；准备工作后置成结尾卡片；可选项明确标「选配」。

> 开篇一句话卖点：**不写一行代码，靠对话让 Codex 把一句话想法做成一只能挂在桌面上的像素桌宠**——你开始专注它就钓鱼，你完成任务小树就成长，这只「工位池塘」就是这么聊出来的。

## 第 0 节 · 成品先行

- 直接放成品：工位池塘挂在桌面角落运行的录屏（无边框、置顶、像素池塘 + 番茄钟 + 任务苗圃），一张水族馆/森林成图
- 一句话交代本章玩法：把想法说给 Codex → 一次加一个功能玩着迭代 → 自检打包 → 双击 exe 挂上桌面
- 一句话呼应母教程：前面章节里有只 Codex 宠物陪你干活，这一章你亲手造一只完全属于自己的

**需要素材**：桌面运行录屏 1 段（需补录）、成品图 1-2 张（`promo/` 现成挑选）

## 第 1 节 · 先认识你的开发班底：Codex + Godot

> 写法：两张小卡片——「它是谁 + 在这个项目里管什么」，各 2-3 句话打住，不讲内部怎么实现。

| 成员 | 一句话身份 | 本项目分工 |
|---|---|---|
| **Codex** | 程序员本体 | 全部代码、界面、像素画面、音效都由它写；你只负责说想要什么、玩一遍提意见 |
| **Godot** | 游戏引擎（免费开源） | Codex 写的东西在它里面变成能跑的窗口，最后也由它打包成双击即用的 exe；你只需要装好它、会点「运行」 |

- 安装只给一句话指路（详见结尾卡片），正文不展开

**需要素材**：班底卡片图 1 张、Godot 打开项目点运行的截图 1 张

## 第 2 节 · 开发实操：从一句话到桌面桌宠

> 主线五步，每步 = 一段对话提示词 + 一张结果截图，全部「对话 + 结果」呈现，不解释背后发生了什么。

### Step 1 · 一句话立项，先要个能跑的最小版

- 提示词模板：
  > 「我想做一个 2D 像素桌面陪伴小游戏：一个小池塘，我点『甩杆』开始专注倒计时，专注结束自动钓上一条鱼；右边能写今日任务，勾完任务小树长一点。用 Godot 帮我搭一个最小可玩版本」
- 结果展示：第一版窗口截图
- 一句话贴士：第一版丑、功能少都没关系，「能跑起来」就是最大的胜利，后面全靠迭代

### Step 2 · 一次加一个功能，玩着迭代

- 展示 3 组真实迭代对话（各一句话提示词 + 结果）：
  1. 「专注结束后自动进休息倒计时，钓到的鱼存进图鉴」→ 番茄钟循环 + 收藏图鉴
  2. 「任务写错了没法改，加个编辑」→ 任务可编辑
  3. 「今天没做完的任务，第二天打开自动带过来」→ 隔日顺延
- 迭代纪律一句话：**一次只提一个功能，自己玩一遍确认了再提下一个**
- 选配一句话：玩法想做大（比如源项目后来的水族馆、森林房间），让 Codex 先写一页设计文档你点头再动工

### Step 3 · 让它像个桌宠：去边框、可置顶

- 提示词模板：
  > 「去掉系统窗口边框，整体统一成极简像素风；顶栏加一个图钉按钮，按下就置顶，让它能一直贴在桌面上」
- 一句话点题：这一步是「一个程序」变成「一只桌宠」的分水岭——没有系统边框、随手一拖、常驻眼角
- 结果展示：去边框前后对比图

### Step 4 · 发布前，让 Codex 全 app 自检一遍

- 提示词模板：
  > 「发布前把整个 app 自己从头过一遍，把发现的问题列出来并修掉，修完给我清单」
- 真实案例：源项目一次自检修掉 6 处问题（如水族馆里的鱼太多把关闭按钮挤出窗外）；更早还修过「弹窗能被拖出屏幕外导致再也点不到」这类小白最容易撞上的 bug
- 一句话贴士：Codex 能自检逻辑 bug，但**验不了好不好看、好不好听**——你必须亲手完整玩一遍再放行
- 结果展示：自检清单对话截图 + 1 组修复前后对比

### Step 5 · 打包成双击即用的 exe

- 提示词模板：
  > 「打包成单个 exe 文件，文件名带上版本号，发我路径」
- 结果展示：文件夹里的 `DeskPond-v0.x.x.exe` + 双击运行画面；无需安装、单文件、拷给朋友也能直接跑
- 收束一句：挂上桌面，从今天起你的番茄钟有鱼可钓了

**需要素材**：5 步各 1-2 张对话/结果截图、去边框前后对比 1 组、自检修复前后对比 1 组

## 第 3 节 · 打磨与出门（选配）

### 3.1 补齐「作品感」三件套（选配，推荐做）

- 一段对话搞定三样：环境水声 + 事件音效（顶栏一键静音）、应用图标、首次打开自动弹一次玩法说明
- 避坑一句话（源项目真踩过）：图标这类**审美产物，让 Codex 先出一张真实尺寸预览图，你点头再定稿**——源项目第一版图标没预览直接用，被「有点丑」打回，重做成彩色 emoji 风才过关

### 3.2 分享给别人（进阶选配，一笔带过）

- 一句话：让 Codex 把 exe 发到 GitHub Releases 生成下载链接；还能导出网页版给手机玩。想深入的学员自行探索，本章不展开
- 收束一句：之后每个新想法都是同一套循环——「对话加功能 → 自己玩一遍 → 自检 → 重新打包」

**需要素材**：图标第一版 vs emoji 版对比图 1 张、顶栏音效/图钉按钮特写 1 张
