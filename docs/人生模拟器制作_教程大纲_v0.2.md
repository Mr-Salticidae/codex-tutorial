## 第 0 节 · 成品先行

- 直接放 30 秒试玩录屏（本机运行截取）：擦亮镜子 → 人生抉择 → 金色人生曲线游过分支图 → 职业小游戏 → 人生报告 + 分享卡
- 一句话背书（纯文字，不配图）：这个模拟器的原型在 BW 展台真实跑了一整个展会，主体就是这么「说」出来的
- 一句话交代本章玩法：把点子讲给 Codex → 浏览器里试玩 → 截图反馈当制作人 → 换上美术图打包分享

**需要素材**：30s 试玩录屏 1 段（本机跑仓库版本录制）

## 第 1 节 · 开工：把点子一段话说清楚

> 写法：一段提示词 + 一份「设计蓝图」+ 一次试玩，三步走完。不讲任何技术名词。

- 提示词模板：
  > 「帮我做一个网页版人生模拟器：玩家从 7 岁到 25 岁做 5 个人生选择，每个选择悄悄影响性格倾向，最后走向军人 / 画家 / 赛车手三种职业结局，各配一个 20 秒小游戏，结尾生成一份专属人生报告和可保存的分享卡。先写一份设计蓝图给我看，确认后再动工」
- **先审蓝图再开工**：Codex 会回一份设计蓝图（源项目同款做法），学员只盯 2 个审核点：①抉择节点表——每个选择分别通向哪；②从头到尾的体验流程顺不顺
- 确认后说「开工，跑起来给我看」：Codex 给一个本地网址，浏览器打开就能从头玩到尾
- 宽心话一句：**没有美术图也能玩**——缺图的地方会自动用占位画面顶着，流程不断（源项目就是先跑通全流程、图后补的）

**需要素材**：开工提示词对话截图 1 张、设计蓝图（节点表部分）截图 1 张、占位图状态下的试玩截图 1 张

## 第 2 节 · 试玩迭代：截图反馈当制作人

> 主线三步，每步 = 一段对话 + 一张结果截图。反馈公式与实战6 同款：**截图 + 圈出来 + 说想要什么**，学员已经会。

### Step 1 · 自己当第一个玩家

- 从头玩一遍，凡是「点不动、看不懂、太挤」的地方都截图存下来
- 避坑贴士（源项目实测教训）：反馈别只说「点不动」——说清「我按了多久、屏幕有什么反应」。源项目就出过一次误判：以为选项坏了，其实是长按钮被短按了一下、没给任何反馈

### Step 2 · 一次改一处

- 放 2 组真实前后对比当案例（均从源项目 git 历史在本机复现）：
  1. 「分支图结局区挤成一团」→ 截图一句话反馈 → 结局框拉开、不再重叠
  2. **说不清楚就画出来**：在截图上手绘一条红线——「人生曲线要这样蜿蜒游过分支图」→ Codex 照着画出金色曲线（本节金句案例；配图为本机重演示意：本地跑起分支图页面截图后重绘红线，图内标注「示意重演」）
- 迭代纪律一句话：一次提一个问题，改完确认再提下一个

### Step 3 · 嫌内容少？一句话扩容

- 提示词模板：
  > 「把人生抉择从 5 个加到 8 个，再加一个隐藏结局和一套称号——玩得好坏拿到的称号不一样」
- 结果展示：一轮对话完成扩容（源项目「迭代一」即如此：节点 5→8、隐藏结局、称号池一次到位）
- 学员唯一的活：把新节点亲手玩一遍，检查每个选择的文案读起来顺不顺

**需要素材**：3 步各 1-2 张对话/结果截图、前后对比 2 组（分支图解挤对比从 git 历史两侧本机复现；红线图为本机重演示意）

## 第 3 节 · 换上真素材，打包带走

- **换剧照**：跟 Codex 说「给每个场景写一份 Midjourney 出图提示词」，出好的图按 Codex 给的文件名放进指定文件夹，刷新网页即生效——不用改任何代码
  - 避坑贴士（源项目两轮返工换来的）：人物的年龄、衣着这类关键点，提示词里要「正着说 + 反着排除 + 给个参照物」，只写一个形容词或数字必跑偏
- **BGM（选配）**：想要就把一首 mp3 按指定文件名放进音频文件夹；不放就静音运行，完全不影响
- **打包分享**：跟 Codex 说「打包成一个能双击打开的文件夹」——发给朋友，零安装、断网也能玩（源项目就是这样上的展台）
- **进阶选配·给报告接上真 AI**：默认的人生报告已会按你的选择自动生成；想让本地 AI 现场「写」报告，改一处配置接上本地模型即可，本教程不展开
- 一句话收束：「一段话点子 → 审蓝图 → 截图迭代 → 换皮 → 打包」这条流程，做任何互动小应用都能复用

**需要素材**：占位图 vs 真剧照同屏前后对比 1 组、MJ 提示词对话截图 1 张、打包产物文件夹 + 双击运行截图 1 张
