# 人生模拟器制作_附件版

**想不想做一个属于自己的人生模拟器？做几个人生选择，走向不同的职业结局，最后还能拿到一份专属人生报告。这一章不写一行代码，靠「一段话点子 + 截图反馈」让 Codex 从零帮你搭出一个能玩、能分享的人生模拟器网页。我们先看成品。**

🔴【此处插入附件：人生模拟器_30s试玩.mp4】

![图01_试玩预览帧.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE01_%E8%AF%95%E7%8E%A9%E9%A2%84%E8%A7%88%E5%B8%A7.png)

擦亮镜子 → 做出人生抉择 → 一条金色人生曲线游过分支图 → 职业小游戏 → 拿到专属人生报告和分享卡。这个模拟器的原型在 BW 展台真实跑了一整个展会——而它的主体，就是靠「说」做出来的。

这一章要教你的玩法就一句话： **把点子讲给 Codex，浏览器里试玩，截图反馈当制作人，最后换上美术图打包分享。** 全程不写一行代码。

**开工：把点子一段话说清楚。** 对 Codex 说出你的点子——一段话，讲清「玩家做什么、通向什么结局」：

帮我做一个网页版人生模拟器：玩家从 7 岁到 25 岁做 5 个人生选择，每个选择悄悄影响性格倾向，最后走向军人 / 画家 / 赛车手三种职业结局，各配一个 20 秒小游戏，结尾生成一份专属人生报告和可保存的分享卡。先写一份设计蓝图给我看，确认后再动工。

![图02_开工提示词对话.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE02_%E5%BC%80%E5%B7%A5%E6%8F%90%E7%A4%BA%E8%AF%8D%E5%AF%B9%E8%AF%9D.png)

注意最后一句—— **先要蓝图，别急着开工。** Codex 会回你一份设计蓝图，你只盯两个审核点：

1. **抉择节点表** ——每个选择分别通向哪，路线合不合理；
2. **体验流程** ——从开场到拿报告，一条线走下来顺不顺。

![图03_设计蓝图节点表.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE03_%E8%AE%BE%E8%AE%A1%E8%93%9D%E5%9B%BE%E8%8A%82%E7%82%B9%E8%A1%A8.png)

没问题就回一句「**开工，跑起来给我看**」。Codex 会给你一个本地网址，浏览器打开，从头玩到尾。

放宽心： **没有美术图也能玩。** 缺图的地方会自动用占位画面顶着，流程不断——图是最后才补的事。

![图04_占位图试玩画面.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE04_%E5%8D%A0%E4%BD%8D%E5%9B%BE%E8%AF%95%E7%8E%A9%E7%94%BB%E9%9D%A2.png)

**接下来进入试玩迭代，截图反馈当制作人。** 主线三步。反馈公式你在实战 6 已经会了： **截图 + 圈出来 + 说想要什么。**

**Step 1 · 自己当第一个玩家。** 从头玩一遍，凡是「点不动、看不懂、太挤」的地方，都截图存下来。

一条避坑贴士：反馈别只说「点不动」—— **说清「我按了多久、屏幕有什么反应」。** 这个项目就出过一次误判：以为选项坏了，其实是长按钮被短按了一下、没给任何反馈。你描述得越具体，Codex 一次改对的概率越高。

![图05_反馈对话.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE05_%E5%8F%8D%E9%A6%88%E5%AF%B9%E8%AF%9D.png)

**Step 2 · 一次改一处。** 两组真实案例：

**案例一：分支图结局区挤成一团。** 截图一句话反馈——下一版结局框拉开，不再重叠。

![图06_分支图解挤前后对比.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE06_%E5%88%86%E6%94%AF%E5%9B%BE%E8%A7%A3%E6%8C%A4%E5%89%8D%E5%90%8E%E5%AF%B9%E6%AF%94.png)

**案例二：说不清楚，就画出来。** 想要「人生曲线蜿蜒游过分支图」，嘴上怎么说都差点意思——那就在截图上手绘一条红线：要的就是这个走势。Codex 照着红线，画出了一条只跟随你选择游动的金色曲线。

![图07_手绘红线示意重演.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE07_%E6%89%8B%E7%BB%98%E7%BA%A2%E7%BA%BF%E7%A4%BA%E6%84%8F%E9%87%8D%E6%BC%94.png)

![图08_金色人生曲线画面.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE08_%E9%87%91%E8%89%B2%E4%BA%BA%E7%94%9F%E6%9B%B2%E7%BA%BF%E7%94%BB%E9%9D%A2.png)

一条迭代纪律： **一次只提一个问题，改完确认了再提下一个。**

**Step 3 · 嫌内容少？一句话扩容。**

把人生抉择从 5 个加到 8 个，再加一个隐藏结局和一套称号——玩得好坏拿到的称号不一样。

一轮对话，节点、隐藏结局、称号池一次到位。你唯一的活： **把新节点亲手玩一遍，检查每个选择的文案读起来顺不顺。**

![图09_扩容对话.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE09_%E6%89%A9%E5%AE%B9%E5%AF%B9%E8%AF%9D.png)

![图10_扩容后分支图.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE10_%E6%89%A9%E5%AE%B9%E5%90%8E%E5%88%86%E6%94%AF%E5%9B%BE.png)

**最后一步：换上真素材，打包带走。**

**换剧照。** 跟 Codex 说「**给每个场景写一份 Midjourney 出图提示词**」，出好的图按它给的文件名放进指定文件夹，刷新网页即生效——不用改任何代码。

一条避坑贴士（两轮返工换来的）：人物的年龄、衣着这类关键点，提示词里要 **「正着说 + 反着排除 + 给个参照物」** ，只写一个形容词或数字必跑偏。

![图11_MJ提示词对话.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE11_MJ%E6%8F%90%E7%A4%BA%E8%AF%8D%E5%AF%B9%E8%AF%9D.png)

![图12_占位图vs真剧照对比.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE12_%E5%8D%A0%E4%BD%8D%E5%9B%BEvs%E7%9C%9F%E5%89%A7%E7%85%A7%E5%AF%B9%E6%AF%94.png)

**BGM（选配）。** 想要就把一首 mp3 按指定文件名放进音频文件夹；不放就静音运行，完全不影响。

**打包分享。** 最后一句话：

打包成一个能双击打开的文件夹。

发给朋友，零安装、断网也能玩——这个项目就是这样上的展台。

![图13_打包产物运行.png](https://raw.githubusercontent.com/Mr-Salticidae/codex-tutorial/main/docs/images/%E4%BA%BA%E7%94%9F%E6%A8%A1%E6%8B%9F%E5%99%A8/%E5%9B%BE13_%E6%89%93%E5%8C%85%E4%BA%A7%E7%89%A9%E8%BF%90%E8%A1%8C.png)

**进阶选配·给报告接上真 AI。** 默认的人生报告已会按你的选择自动生成；想让本地 AI 现场「写」报告，改一处配置接上本地模型即可，本章不展开。

收个尾：「一段话点子 → 审蓝图 → 截图迭代 → 换皮 → 打包」，这条流程做任何互动小应用都能复用——下一个点子，还是从一段话开始。
