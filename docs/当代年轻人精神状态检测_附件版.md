# 当代年轻人精神状态检测：一句话做出能伪装成工作问卷的趣味测试

**如果你想做一个能让朋友忍不住转发的小测试，离成品还有多远？这一次不需要搭服务器，也不用准备图片素材。我们用 Codex 做一个“当代年轻人精神状态检测”：回答 16 个生活场景问题，最后拿到一份带点扎心、又不会冒犯人的精神状态报告。老板路过时，还能一键切换成正经的员工调研问卷。我们先来看一下 Codex 的成品。**

整个体验只有一条主线：进入检测 → 回答 16 个情境问题 → 等待“值班医生”分析 → 查看专属结果 → 复制分享文案。所有样式和逻辑都装在一个 `index.html` 文件里，双击就能运行。

**开工：先把玩法和边界说清楚。** 对 Codex 说：

```text
帮我做一个单文件网页版“当代年轻人精神状态检测”。玩家回答 16 个日常情境选择题，选项分别影响社交、共情、敏感、低电量、想太多、直球、计划型和平衡型八项倾向，最后生成一种趣味结果。页面要有娱乐化文案、答题进度、返回上一题、加载动画、结果报告和分享文案。

再增加一个“办公保护模式”：一键把标题、题目和结果包装成员工工作状态与协作体验调研，但底层评分保持一致。整个项目只使用一个 index.html，不依赖构建工具。先给我设计蓝图，确认后再动工。
```

注意最后一句：**先看蓝图，再让 Codex 写页面。**

蓝图阶段只审核三件事：

1. 16 道题是否覆盖不同生活场景，而不是反复问同一件事；
2. 8 种结果是否有清楚区别，又不会像医学诊断；
3. 娱乐模式和办公模式是否共享同一套答题逻辑。

**第一轮：先跑通，不急着追求完美。** 确认蓝图后，对 Codex 说：

```text
开工。先完成可双击运行的单文件版本，题目、评分、结果和模式切换全部跑通，再做视觉细节。
```

初版最重要的不是动画，而是能从首页一路答到结果页。当前版本一共 16 题，每一题都是年轻人熟悉的具体场景：临时邀约、老板找你聊一下、凌晨回想尴尬瞬间、群聊任务、外卖选择、朋友说“没事”、计划被打乱等。

🔴【此处插入图02_娱乐模式答题页 ｜ 源文件：docs/images/当代年轻人精神状态检测/图02_娱乐模式答题页.png】

具体场景比抽象问题更容易回答。与其问“你是否容易过度思考”，不如问“发完重要消息后，你接下来会做什么”。玩家不用分析自己，只需要选择最像真实反应的答案。

**这次真正有用的创意：办公保护模式。** 页面右上角可以切换办公模式。切换后，同一套测试会变成员工工作状态与协作体验调研：标题、说明、题目和结果全部换成正式表达，页面视觉也从娱乐风格变成办公文档。

🔴【此处插入图03_办公保护模式 ｜ 源文件：docs/images/当代年轻人精神状态检测/图03_办公保护模式.png】

这里不需要维护两套评分系统。娱乐题目和办公题目按顺序一一对应，玩家切换模式后仍然停留在当前题目，已经做过的选择也不会丢失。

快捷键也被保留下来：按 `Esc` 进入办公模式，按 `Alt+Q` 可以在两种模式之间切换。

**试玩迭代：一次只检查一个问题。** 从头玩一遍时，不要只看页面漂不漂亮。依次检查：

- 每个选项能否点击；
- 题目序号和进度条是否同步；
- 返回上一题后，旧分数是否正确撤销；
- 中途切换模式后，当前题号是否保持；
- 第 16 题完成后是否进入加载页；
- 结果页按钮是否都能使用。

🔴【此处插入图04_答题进度与返回修改 ｜ 源文件：docs/images/当代年轻人精神状态检测/图04_答题进度与返回修改.png】

反馈仍然使用最简单的公式：**截图 + 圈出问题 + 描述实际反应和期望反应。**

例如：

```text
我在第 8 题切换办公模式后，页面回到了首页。我希望切换只改变外观和文案，保留当前题号和已经完成的答案。
```

这比只说“切换有问题”更容易让 Codex 一次修对。

**结果不是医学诊断，而是可分享的人格梗。** 完成答题后，页面会进入一段模拟分析过程，再从八种类型中生成结果，例如“脑内编剧”“低电量模式”“共情雷达”“计划守护者”和“六边形青年”。

每份结果包含类型名称、一句话总结、近期高发行为和一段温和建议。这里要守住一个边界：它是趣味内容，不应写成心理或医学诊断。文案可以扎心，但不能给玩家贴病理标签。

**分享：先做文案，再考虑复杂海报。** 结果页可以调用系统分享；不支持系统分享时，就自动复制结果文案。这样不用先做复杂的分享卡生成器，也能完成传播闭环。

页面还提供二维码入口。部署到线上后，二维码可以让朋友扫码打开测试；本地双击版本仍然可以完整答题，但二维码生成需要联网。

```text
精神状态检测-V1.5-稳定优化自检版/
├── index.html
└── README.txt
```

双击 `index.html` 就能运行，不需要安装依赖。发给朋友时，把整个文件夹压缩成 ZIP 即可。页面主体不依赖外部图片、CSS 或 JavaScript，断网也可以完成检测和查看结果。

需要注意：当前版本的答题状态只在页面本次打开期间保留，刷新后会重新开始；二维码需要联网生成。不要在教程里把这两点写成“刷新后自动续答”或“完全离线二维码”。

从这个项目可以复用的流程是：**一句话讲清玩法 → 先审题目与结果蓝图 → 跑通单文件版本 → 用截图逐项反馈 → 增加一个记忆点功能 → 打包分享。**
