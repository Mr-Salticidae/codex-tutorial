##### 桌面小程序开发（跳）

**还记得前面章节里，那只陪你干活的 Codex 宠物吗？这一章，你亲手造一只完全属于自己的桌面桌宠。写代码、画像素画面、配音效、打包成双击就能用的 exe——这些活现在 AI 都能干，你只负责说想要什么。你点「甩杆」开始专注，它就开始钓鱼；你完成任务，小树就长一点。我们先来看一下 Codex 的成品。**

[请至钉钉文档查看附件《工位池塘\_桌面运行.mp4》。](https://alidocs.dingtalk.com/i/nodes/OG9lyrgJPz1GEo2YIvM9B57rWzN67Mw4?iframeQuery=anchorId%3DX02mrsu0fbx4wbv363uoey)

![图01_桌面一角实拍.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/ce13a888-43f8-4370-80fe-07a3248eb07b.png)

这只「工位池塘」就挂在桌面角落陪你干活：你点「甩杆」开始专注，小人就开始钓鱼；专注结束自动钓上一条鱼；右边写今日任务，勾完一条，小树就长一点。钓来的鱼住进水族馆，种下的树连成森林。

![图02_森林与水族馆.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/06a89b58-1bf7-4012-bc74-d50216198d6f.png)

玩法一句话：**把想法说给 Codex → 一次加一个功能玩着迭代 → 自检打包 → 双击 exe 挂上桌面。**

**先认识你的开发班底：Codex + Godot。**

![图03_开发班底卡片.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/de189c46-d838-485c-8b4c-02fe9a4048f8.png)

*   **Codex —— 程序员本体。** 全部代码、界面、像素画面、音效都由它写；你只负责说想要什么，和玩一遍提意见。
    
*   **Godot —— 免费开源的游戏引擎。** Codex 写的东西在它里面变成能跑的窗口，最后也由它打包成双击即用的 exe；你只需要装好它、会点右上角的「运行 ▶」。
    

![图04_Godot打开项目点运行.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/37a691d6-dea5-4499-aed7-fbe6a6255e24.png)

安装就一句话：官网下载、装好、能打开就行（详见文末准备清单）。

**接下来进入开发实操，从一句话到桌面桌宠。** 主线五步，每步就是一段对话。

**Step 1 · 一句话立项，先要个能跑的最小版。**

我想做一个 2D 像素桌面陪伴小游戏：一个小池塘，我点「甩杆」开始专注倒计时，专注结束自动钓上一条鱼；右边能写今日任务，勾完任务小树长一点。用 Godot 帮我搭一个最小可玩版本。

![图05_一句话立项对话.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/b0a178ee-6412-44ee-8542-97c844a2c61b.png)

第一版长这样——灰底方块、文字凑合，但番茄钟能走、任务能记：

![图06_第一版最小版本.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/28656162-85bf-4e4e-8982-3e0baf64abce.png)

一句话贴士：**第一版丑、功能少都没关系，「能跑起来」就是最大的胜利**，后面全靠迭代。

**Step 2 · 一次加一个功能，玩着迭代。** 三组真实迭代，每组就一句话：

![图07_三组迭代对话.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/b61dd044-9697-4fda-881e-bf0a0a2698b4.png)

「专注结束自动进休息」变成了会自己循环的番茄钟；「钓到的鱼存进图鉴」变成了每条鱼有名字有小传的收藏册：

![图08_迭代成果_鱼类图鉴.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/ea27bffd-ae0e-4332-8c87-06b966bf3a74.png)

迭代纪律一句话：**一次只提一个功能，自己玩一遍确认了再提下一个。**

选配一句话：玩法想做大（比如这个项目后来的水族馆、森林房间），让 Codex 先写一页设计文档，你点头再动工。

**Step 3 · 让它像个桌宠：去边框、可置顶。**

去掉系统窗口边框，整体统一成极简像素风；顶栏加一个图钉按钮，按下就置顶，让它能一直贴在桌面上。

![图09_桌宠化对话.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/89dd9bb7-92c5-4dc4-af3a-917598eaf118.png)

这一步是「一个程序」变成「一只桌宠」的分水岭——没有系统边框、随手一拖、常驻眼角：

![图10_去边框前后对比.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/dc5adb61-cf9b-4551-b598-bf8e73a01aa2.png)

**Step 4 · 发布前，让 Codex 全 app 自检一遍。**

发布前把整个 app 自己从头过一遍，把发现的问题列出来并修掉，修完给我清单。

![图11_自检清单对话.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/ce4df416-6f4f-40b3-be51-6adef188a17a.png)

这个项目的一次真实自检，一口气修掉 6 处问题——比如水族馆鱼钓多了以后，顶栏被撑爆，右上角关闭按钮被挤出窗外：

![图12_自检修复前后对比.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/2fba0ce7-4693-45a6-81cd-05669d3a77d8.png)

一句话贴士：Codex 能自检出逻辑 bug，但**验不了好不好看、好不好听**——发布前你必须亲手完整玩一遍再放行。

**Step 5 · 打包成双击即用的 exe。**

打包成单个 exe 文件，文件名带上版本号，发我路径。

![图13_打包产物与运行画面.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/5879a4c0-7576-4682-ab2c-b2edb6cca3c8.png)

单文件、无需安装，拷给朋友也能直接跑。挂上桌面——从今天起，你的番茄钟有鱼可钓了。

**打磨与出门（选配）。** 一段对话搞定「作品感」三件套：环境水声 + 事件音效（顶栏一键静音）、应用图标、首次打开自动弹一次玩法说明。

避坑一句话（这个项目真踩过）：图标这类**审美产物，让 Codex 先出一张真实尺寸预览图，你点头再定稿。** 源项目第一版图标没预览直接用，被「有点丑」打回，重做成彩色 emoji 风才过关：

![图14_图标对比与顶栏特写.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmGKj5dkXOm9/img/8ef60f92-54d0-4c44-95d8-807d7c8cfc68.png)

分享给别人（进阶选配）一句话：让 Codex 把 exe 发到 GitHub Releases 生成下载链接；还能导出网页版给手机玩。想深入的自行探索，本章不展开。

收束一句：之后每个新想法都是同一套循环——**对话加功能 → 自己玩一遍 → 自检 → 重新打包。**
