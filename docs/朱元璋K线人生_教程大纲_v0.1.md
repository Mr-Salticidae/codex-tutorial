# 朱元璋K线人生_教程大纲_v0.1

## 板块定位

这一板块把朱元璋的一生做成一个动态 Web 应用：用 K 线图隐喻命运、权力、风险和代价的变化。它不是历史论文，也不是金融分析，而是一个给 Codex 小白看的“如何把抽象想法落成可交互作品”的案例。

成品入口：`apps/zhuyuanzhang-kline/index.html`

## 观看规则

- 开盘价：阶段起点的处境。
- 收盘价：阶段结束后的处境。
- 最高价：阶段内曾经触及的机会或权力上限。
- 最低价：阶段内承受的风险、危机或代价。
- 冲击量：该事件对人生走势的改变强度。

所有数值都是叙事指数，只用于帮助读者看懂趋势，不代表真实史学定量结论。

## 制作侧附注

这一页采用纯 HTML、CSS、Canvas 和原生 JavaScript，不引入构建链。新版改为一页自适应铺满：桌面端让图表占据主要视口，标题、指标、事件说明和播放控制压到边缘；手机端保留主图优先，历史节点改为底部横滑轨道。风格对齐 `E:\above-the-web`：暖白纸面、细线分隔、宋体标题、克制紫色作为主站识别色；为贴合明代主题，补入朱砂红、玉绿色和金色，但不让页面变成重装饰古风。

核心实现分三步：

1. 先把历史节点转成结构化数组，每个节点包含 `year`、`title`、`open`、`high`、`low`、`close`、`volume` 和 `note`。
2. 用 Canvas 根据当前视口尺寸绘制坐标、影线、实体、均线、冲击量柱和当前事件高亮。
3. 用 `requestAnimationFrame` 驱动逐根 K 线出现，并提供播放、重播、下一根和历史节点跳转。
4. 用 980px、640px、390px 三层媒体查询兜底，分别处理平板、常见手机和极窄屏的文字压缩与控件换行。

## 教程展开建议

正文可以按“先收束隐喻，再定数据口径，再做交互页”的顺序写。重点不是讲 Canvas API 的每一个细节，而是让学员看到：一个模糊创意可以先被压成一张数据表，再由 Codex 生成可视化结构，最后通过自检修掉可读性问题。
