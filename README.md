## 三、制作流程（每板块照此执行）

```text
① 确认素材完结：成品/上线版本 + 复盘 + git 历史齐备，缺一先补一
② 反推制作流程：只从复盘文档、git 提交串、真实产物还原步骤，不凭记忆写
③ 大纲先行：正文一字不写，先出大纲；大纲末尾附「制作侧附注」
   （素材缺口清单 + 篇幅预估 + 删改内容去向）
④ 审核：作者（跳蛛先生）单级审核 —— 本期免上级二级审核
⑤ 大纲过审后展开正文 + 配图（截图优先真实界面；示意图需图内标注）
⑥ 附件版：按钉钉格式白名单收敛（修饰仅加粗+代码块，禁引用块/表格/多级小标题）
```

学员版写作遵循**减负三原则**：只讲工具「是谁、管什么」不讲底层原理；准备工作后置成结尾卡片；可选项明确标「选配」。

## 四、交付物（每板块一套）

1. **教程大纲**（含制作侧附注，作者过审）
2. **教程正文定稿 + 配图**（`docs/images/<板块>/`）
3. **附件版**（钉钉母文档格式，供并入母教程）

## 五、目录结构

```text
docs/                 大纲、正文、附件版（文件名：<板块名>_教程大纲_v0.1.md 等）
docs/images/          配图，按板块分子目录
reference/            母教程节选、源项目复盘等参考资料（只读引用，不改写）
```
